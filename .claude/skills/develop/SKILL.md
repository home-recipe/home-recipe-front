# /develop - 기능 개발 자동화 커맨드

사용자가 구현을 요청한 기능: $ARGUMENTS

## 실행 지침

아래 단계를 **순서대로** 실행하세요.

### Step 1: 프로젝트 규칙 확인

먼저 다음 파일들을 읽어서 프로젝트 규칙과 컨텍스트를 파악하세요:
- `.claude/skills/` 디렉토리의 모든 스킬 파일 (Glob으로 검색)
- `CLAUDE.md` 파일 (존재하는 경우)
- 프로젝트 루트의 `README.md` (존재하는 경우)

이 내용들은 이후 모든 서브에이전트에게 전달해야 합니다.

### Step 2: requirement-planner 서브에이전트로 요구사항 분석

Task 도구를 사용하여 `requirement-planner` 서브에이전트를 실행합니다.

프롬프트에 반드시 포함할 내용:
- 사용자 요청: "$ARGUMENTS"
- 프로젝트 경로: /Users/mikyeong/project/home-recipe-front
- Step 1에서 확인한 프로젝트 규칙 내용 전체
- 프로젝트의 기존 코드와 구조를 분석하여 요구사항 정의서와 구현 계획을 작성할 것
- 결과를 구조화된 형식(요구사항 정의서 + 구현 계획)으로 반환할 것

### Step 3: 사용자 승인

requirement-planner의 결과(요구사항 정의서 + 구현 계획)를 사용자에게 보여주세요.
그리고 AskUserQuestion 도구를 사용하여 다음을 확인하세요:
- 계획대로 구현을 진행할지
- 수정할 부분이 있는지

사용자가 수정을 요청하면 해당 내용을 반영한 후 다시 승인을 받으세요.

### Step 4: senior-code-architect 서브에이전트로 코드 구현

사용자 승인 후, Task 도구를 사용하여 `senior-code-architect` 서브에이전트를 실행합니다.

프롬프트에 반드시 포함할 내용:
- Step 2에서 작성된 요구사항 정의서와 구현 계획 **전체 내용**
- Step 1에서 확인한 프로젝트 규칙 내용 전체
- 프로젝트 경로: /Users/mikyeong/project/home-recipe-front
- 프로젝트의 기존 패턴과 컨벤션을 따를 것
- 코드 구현 후 자체 품질 리뷰를 수행할 것

### Step 5: 최종 결과 보고

구현 완료 후 다음을 포함한 요약을 사용자에게 제공하세요:
- 구현 완료된 기능 요약
- 생성/수정된 파일 목록
- 테스트 또는 확인 방법 안내
- 추가 작업이 필요한 사항 (있다면)

## 중요 규칙

- **스킬 참고 필수**: 서브에이전트 실행 시 `.claude/skills/` 의 규칙 내용을 항상 프롬프트에 포함하세요
- **승인 후 구현**: Phase 1 결과를 사용자에게 보여주고 승인받은 후에만 코드 구현을 진행하세요
- **진행 상황 공유**: 각 단계의 시작과 완료를 사용자에게 알려주세요
- **기존 코드 존중**: 프로젝트의 기존 아키텍처와 패턴을 최대한 따르세요
